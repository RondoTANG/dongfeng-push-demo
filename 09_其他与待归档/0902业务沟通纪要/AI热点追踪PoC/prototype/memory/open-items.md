# 待确认事项

## OI-001 Codex 企业化执行方式

- 当前结论：本地 PoC 已用本机已登录 Codex CLI 执行与豆包相同的基础查询，并可作为定向补证手段。这是本地 PoC 执行方式，不是企业级数据源承诺。
- 本期默认：双路基础查询与补证均可执行，但自动每3小时采集保持暂停。
- 后续确认：企业环境采用 Codex 自动化、其他 Agent、消息推送消费还是受控 MCP。
- 是否阻塞：不阻塞页面与本地流程实现。

## OI-002 豆包返回稳定性

- 当前结论：实测成功响应的 `web_search_items_json` 为 JSON 字符串，字段包含标题、URL、域名、站点、权威等级、发布时间、摘要和 request_id。
- 本期默认：适配当前结构并保留请求级原始响应索引；解析失败进入失败记录和审计。
- 后续确认：接口版本升级、限流策略和企业级 SLA。
- 是否阻塞：不阻塞。

## OI-003 事件自动聚合阈值

- 当前结论：规则要求按主体、动作、时间和证据相似度聚合，但缺少经过标注的阈值样本。
- 本期默认：URL／标题规范化＋品牌／主体＋日期窗口的确定性初聚合，支持运营人工合并和拆分。
- 后续确认：积累 30–50 个真实样本后评估语义聚类阈值。
- 是否阻塞：不阻塞。

## OI-004 官方域名与账号清单

- 当前结论：来源字典已经有平台与部分域名规则，但 9 个品牌的完整官方域名和官方账号仍不齐。
- 本期默认：已配置项正常识别，未命中项标记 `unresolved` 并在配置页可维护。
- 后续确认：运营／品牌方补齐官方账号清单。
- 是否阻塞：不阻塞。

## OI-005 AI 模型与草案质量门槛

- 当前结论：本期使用 Codex 完成补证、语义归纳和草案初稿，尚无固定模型版本、标准样本和通过率基线。
- 本期默认：所有 AI 结果进入人工审核；页面展示证据、禁用表述和存疑原因。
- 后续确认：按历史样本建立草案事实准确率、可用率和修改率指标。
- 是否阻塞：不阻塞。

## OI-006 护卫军标签与正式作业接口

- 当前结论：现有平台能力标签可作为建议选人依据，但本期不接正式标签查询和作业发布接口。
- 本期默认：标签从本地配置读取；草案审批后只记录结果，不推送。
- 后续确认：真实标签接口、业务系统消费方式、审批后数据契约。
- 是否阻塞：不阻塞本期，阻塞正式发布。

## OI-007 三小时运行量与查询成本

- 当前结论：计划覆盖 9 品牌＋8 行业主题，并在行业事件后执行品牌关联补采；本期不以免费额度限制方案。
- 本期默认：页面提供“快速验证”和“完整运行”两种手工模式；启动服务不自动采集，完整运行3小时、快速验证10分钟内不得重复发起。
- 后续确认：连续运行一周后再确定超时、并发、频控和预算。
- 是否阻塞：不阻塞。

## OI-008 热点数据准入

- 当前结论：搜索数据不具备平台原生互动量、连续快照、UGC／作者标识和覆盖审计时，热点固定不可判定。
- 本期默认：配置页展示准入规则但不提供虚假的热点开关。
- 后续确认：专业舆情／平台原生数据源及其字段、覆盖和 SLA。
- 是否阻塞：不阻塞线索 PoC，阻塞真实热点判断。

## OI-009 原创后效快照与增长判断口径

- 当前结论：本地原型支持现有采集服务、业务推送或人工凭证写入同一原创内容的指标快照；至少两个同口径快照后计算首末增量，由运营决定是否生成二次加热草案。
- 本期默认：不设置跨平台统一增长阈值，不因单个指标上涨自动下结论；公众号、视频号没有自动采集时使用人工凭证。
- 后续确认：各平台指标映射、快照窗口与最小间隔、数据回退处理、增长阈值、二次加热人数／动作／频控。
- 是否阻塞：不阻塞链路PoC，阻塞自动化判断和正式作业下发。
