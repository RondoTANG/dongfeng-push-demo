01 / OVERVIEW

整体调用链路

当前方案

两个智能体由业务系统串联。第一段负责把运营提供的多模态材料整理为受控总结；第二段只消费该总结，按前端选择生成评论或直播公屏话术。

BUSINESS SYSTEM
业务系统提交作业材料

作业名称、场景、文本、链接、图片、视频及直播时间。

Start 入参
→
AGENT 01
作业背景内容提取

统一提取材料；直播场景可联网补充，最终返回一段带固定标签的总结。

response.output : String
→
AGENT 02
互动话术生成

将上一步总结作为content，按风格、数量和字数生成前端可展示的话术。

response.comments : Array<String>
唯一字段映射：智能体一的 output 原样写入智能体二的 content。禁止先交给第三个生成式模型改写、重组或“优化JSON”。
02 / AGENT 01

智能体一：作业背景内容提取工作流

HiAgent 工作流
调用对象
HiAgent已发布工作流
请求方式
由AI中台Endpoint决定
业务输出
output / String
典型耗时
多模态与直播搜索较长

请求入参

字段名 类型 必填 业务含义与规则 示例
task_name String 必填 作业名称。当前工作流保留该字段；不得假设它会替代具体背景材料。 星海V6直播任务
scene_type String 必填 场景枚举：comment普通评论，live直播话术。决定是否进入联网搜索分支。 live
task_start_time String 选填 直播开始时间，用作联网资料的时间与阶段判断。建议使用ISO日期或统一业务时间格式。 2026-08-13
task_end_time String 选填 当前已跑通工作流未使用该字段，仅为兼容业务系统保留。 2026-08-13
text_materials String 选填 运营填写的一段自由文本，可包含标题、简介、行程、嘉宾、产品要点或备注。 直播聚焦大六座空间...
url_materials Array<String> 选填 外链数组，每个URL独立提取。无链接时传空数组，不传空字符串。 ["https://..."]
image_materials Array<Image File> 选填 图片文件数组。实际传输结构使用HiAgent/AI中台文件上传协议，不在本业务契约中假设URL或Base64。 []
video_materials Array<Video File> 选填 视频文件数组。实际传输结构使用HiAgent/AI中台文件上传协议。 []
组合校验：text_materials、url_materials、image_materials、video_materials至少一项应有有效内容，否则无法形成可用总结。数组类字段建议始终传数组，空值使用 []。

请求示例（纯文本直播场景）

REQUEST · 逻辑业务对象
{
  "task_name": "东风风行星海V6直播任务",
  "scene_type": "live",
  "task_start_time": "2026-08-13",
  "task_end_time": "2026-08-13",
  "text_materials": "星海V6全国预售发布会，重点介绍大六座空间和华为乾崑相关内容。",
  "url_materials": [],
  "image_materials": [],
  "video_materials": []
}

业务出参

字段名 类型 业务说明 下游用途
output String 最终总结正文。可能包含【主题概括】【官方已知/核心内容】【联网补充】【时间与安排】【可用话术角度】【信息边界】等段落。 保存为AI内容总结，并原样传给智能体二的content。
RESPONSE · 业务字段
{
  "output": "【主题概括】东风风行星海V6全国预售发布会。\n\n【官方已知】本次活动聚焦大六座空间与智能化内容。\n\n【联网补充】……\n\n【可用话术角度】……\n\n【信息边界】未确认信息不得写成确定事实。"
}
平台响应外壳：HiAgent或AI中台实际接口可能在业务字段外增加 code、message、request_id、data 等包装。研发应先按平台文档拆包，再取得本节定义的 output；外壳字段不在本指南中臆造。
03 / AGENT 02

智能体二：互动话术生成智能体

直接调用对话智能体
调用对象
对话智能体
推荐模式
关闭推理 · 快速生成
业务输出
comments / Array<String>
兼容策略
scene_type缺失默认comment

请求入参

字段名 类型 必填 业务含义与规则 示例
content String 必填 主题内容。必须直接使用智能体一的output，不得只截取某一段或擅自扩写。 【主题概括】...
scene_type String 选填 只有明确传live才使用直播公屏规则；为空、缺失、null或其他值时默认按comment普通评论处理。 live
comment_style String 必填 前端选择的一个或多个话术风格；多个风格使用顿号分隔。风格只影响表达，不覆盖事实边界。 好奇追问、细节观察
num Integer / String 必填 生成数量，必须是正整数。业务系统应对返回数组长度进行二次校验。 5
word_count String 必填 单个目标字数或字数区间。目标值/区间下限不得小于5；支持8、8-20等形式。 8-20

请求示例

REQUEST · 直播话术
{
  "content": "【主题概括】东风风行星海V6全国预售发布会。\n\n【官方已知】本次活动聚焦大六座空间与智能化内容。\n\n【信息边界】未确认信息不得写成确定事实。",
  "scene_type": "live",
  "comment_style": "好奇追问、细节观察",
  "num": 5,
  "word_count": "8-20"
}

业务出参

字段名 类型 业务说明 业务校验
comments Array<String> 生成的话术数组。正常情况下数组长度等于num；每一项是一条可供前端预览、选择或复制的话术。 JSON可解析、类型为数组、数量一致、逐条中文汉字数符合word_count。
RESPONSE · 正常结果
{
  "comments": [
    "大六座空间怎么布局",
    "大六座让全家更从容",
    "期待现场讲讲智能化",
    "这场预售直播值得蹲",
    "第三排体验想听细说"
  ]
}
RESPONSE · 无效入参或无有效主题
{
  "comments": []
}
响应拆包：上表是Prompt约定的本体JSON。对话智能体平台可能将其作为字符串放在 answer、output、content 或其他Envelope字段中；AI中台应按实际平台协议先取出原始正文，再执行一次JSON反序列化得到 comments。
生成式结果边界：Prompt不能100%保证JSON、数量和字数。业务系统必须做确定性校验；解析失败、数量不符或字数超限时，可按原参数重试一次。不得把未校验结果直接用于自动发布、计费或积分结算。
04 / FIELD MAPPING

两个智能体的字段映射

智能体一响应 output : String

完整保留段落标签、换行、事实边界和联网补充。

→
智能体二请求 content : String

原样赋值，不二次总结，不只截取“主题概括”。

业务字段 智能体一 智能体二 对接规则
场景类型 scene_type必填 scene_type选填 新业务建议两段传同一个值；旧评论调用不传第二段时默认comment。
主题总结 output出参 content入参 一对一原样映射，是两段链路唯一必需的数据传递。
风格、数量、字数 无 comment_style / num / word_count 由前端用户选择，只影响生成阶段，不触发背景重新提取。
生成结果 无 comments出参 校验通过后用于预览、选择和复制。

05 / ERROR HANDLING

异常处理与确定性校验

异常场景 业务系统处理 禁止行为
智能体一超时或平台调用失败 记录平台请求ID和错误；提示运营稍后重试。不得继续调用智能体二。 不得以空字符串或作业名称替代完整总结。
智能体一output为空或无有效资料 保留运营原材料，提示补充背景信息后重新总结。 不得让话术智能体根据常识自行补全。
智能体二输出不是合法JSON 去除首尾空白后解析；仍失败则按原参数重试一次，并记录原始响应。 不得再调用另一个大模型“修复JSON”。
comments数量或字数不合格 判定本次生成不可用；原参数重试一次。再次失败则提示重新生成。 前端不得静默截断话术或随意拼接补足。
scene_type缺失 智能体一：请求前拦截；智能体二：按普通评论兼容处理。 不得根据总结文本猜测第二段是直播场景。

话术结果最小校验

VALIDATION · JavaScript示例
function chineseCharCount(text) {
  return (String(text).match(/\p{Script=Han}/gu) || []).length;
}

function parseWordCount(value) {
  const normalized = String(value).trim().replace(/[~～—至]/g, "-");
  const numbers = normalized.split("-").filter(Boolean).map(Number);
  if (numbers.length === 1 && Number.isFinite(numbers[0]) && numbers[0] >= 5) {
    return [Math.max(5, numbers[0] - 2), numbers[0] + 2];
  }
  if (numbers.length === 2 && numbers.every(Number.isFinite)
      && numbers[0] >= 5 && numbers[1] >= numbers[0]) {
    return numbers;
  }
  throw new Error("word_count格式无效");
}

function validateComments(comments, expectedNum, wordCount) {
  if (!Array.isArray(comments) || comments.length !== Number(expectedNum)) {
    throw new Error("comments数量不符合请求");
  }

  const [min, max] = parseWordCount(wordCount);
  for (const item of comments) {
    if (typeof item !== "string") throw new Error("comments元素必须是String");
    const count = chineseCharCount(item);
    if (count < min || count > max) throw new Error("话术中文汉字数超限");
  }
}
响应安全原则：两个接口的原始响应应落入受控日志或调用追踪；业务字段由代码解析和校验。需要机器解析的JSON结果，不经过外层生成式智能体做字符级透传。
06 / CHECKLIST

上线前联调清单

确认后冻结契约
补齐两套真实Endpoint、工作流/智能体ID和鉴权Header。
确认图片、视频文件数组在AI中台接口中的真实上传结构。
确认平台外层响应如何取得智能体一的output。
确认平台外层响应如何取得并解析智能体二的JSON正文。
联调普通评论：智能体二不传scene_type，验证默认评论。
联调直播：两段均传scene_type=live，验证联网与直播话术。
联调多素材：文本、链接、图片、视频同时非空，确认全部分支执行。
验证空材料、超时、非法JSON、数量不符和字数超限的失败路径。
前端只展示通过业务校验的comments，支持重新生成和复制。
确认超时、重试、限流、日志脱敏和调用ID追踪策略。
