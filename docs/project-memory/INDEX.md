# 项目索引

> 本文件用于定位，不替代源代码。最后核实：2026-07-28。

## 项目概览

- 产品目标：把跨平台企业宣传动作转为可配置、可分发、可执行、可审核、可结算和可分析的作业闭环。
- 核心用户：护卫军网评员/员工、集团与品牌运营、审核人员、组织管理者。
- 资产形态：PRD、Markdown 规则、HTML 原型、Python Demo、AI Prompt/工作流、审核样本、Office 文档及生成脚本。
- 技术形态：非单体应用；以静态 HTML/JavaScript 原型和 Python Demo 为主，局部使用 Node 工具链、GitHub Pages、阿里百炼/擎天工作流及外部平台接口。
- 根入口：`index.html`；公众号监控 Demo 入口为 `dashboard.html`、`engine.py`；各子项目有独立入口。
- 全局上下文：`.agents/PROJECT_UNDERSTANDING.md`。

## 跨模块关系

- 用户/组织/标签决定作业分发范围和统计口径。
- 作业配置决定 AI 审核入参、证据数量、积分结算和消息触达。
- AI 结果进入人工复核、申诉、积分和统计链路。
- XP 长期蓝图依赖作业、审核、积分、用户和组织数据，但当前暂停。

## 高风险区域

- 最新刚性节点与仓库内原型完成度不等价，先核实上线状态。
- AI Prompt 版本多、样本多，需用真实失败样本验证，不能凭文档宣称生产准确。
- 组织名称存在简称/全称和重复项，关联必须依赖稳定 ID。
- 根公众号实现为 JSON 文件存储 Demo，不可直接视为生产架构。
- 工作区已有大量用户未提交改动，修改时避免覆盖。
